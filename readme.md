# نیوزسیک | Newseek

**Newseek** یک ابزار تحت وب و PWA برای ساخت پرامپت حرفه‌ای جستجوی اخبار است که موضوعات موردعلاقه کاربر را به یک پرامپت ساختاریافته برای پیدا کردن مهم‌ترین و جدیدترین اخبار با کمک مدل‌های هوش مصنوعی تبدیل می‌کند.

نسخه آنلاین:  
https://hamedshabanzadeh.github.io/Newseek/

## درباره Newseek

ابزار Newseek به‌جای اینکه خودش یک خبرخوان یا موتور جستجوی مستقل باشد، به کاربر کمک می‌کند درخواست جستجوی اخبار خود را به‌صورت دقیق و حرفه‌ای آماده کند.

کاربر موضوعات موردنظر و تنظیمات جستجو را انتخاب می‌کند و Newseek بر اساس آن‌ها یک پرامپت ساختاریافته می‌سازد. این پرامپت برای کشف، اعتبارسنجی، ارزیابی، حذف خبرهای تکراری، انتخاب خبرهای مهم و تکمیل اطلاعات خبر طراحی شده است.

پس از ساخت پرامپت، کاربر می‌تواند آن را کپی کند یا مستقیماً یکی از مدل‌های هوش مصنوعی پشتیبانی‌شده را باز کند. با انتخاب مدل، پرامپت ابتدا کپی می‌شود و کافی است کاربر آن را در مدل موردنظر Paste کند.

ابزار Newseek همچنین به‌صورت Progressive Web App ارائه می‌شود و کاربران می‌توانند در صورت تمایل آن را روی موبایل، تبلت یا دسکتاپ نصب و مانند یک وب‌اپ مستقل اجرا کنند. نصب PWA اختیاری است و نسخه وب بدون نیاز به نصب همچنان قابل استفاده است.

## نحوه استفاده

1. موضوع یا موضوعات موردعلاقه خود را اضافه کنید.
2. بازه زمانی، تعداد خبر، زبان و سایر تنظیمات را انتخاب کنید.
3. روی دکمه «ساخت پرامپت» بزنید.
4. پرامپت تولیدشده را بررسی یا کپی کنید.
5. یکی از مدل‌های هوش مصنوعی را انتخاب کنید.
6. پرامپت کپی‌شده را در مدل Paste و اجرا کنید.

## نصب به‌صورت PWA

ابزار Newseek بدون نصب نیز مستقیماً از طریق مرورگر قابل استفاده است.

در موبایل و تبلت، هنگام اولین ورود یک راهنمای کوتاه برای افزودن Newseek به Home Screen نمایش داده می‌شود. این راهنما فقط یک بار نمایش داده می‌شود و نصب برنامه اجباری نیست.

در دستگاه‌ها و مرورگرهای پشتیبانی‌شده، کاربر می‌تواند Newseek را به Home Screen اضافه یا به‌صورت Web App نصب کند. پس از نصب، Newseek در حالت `standalone` اجرا می‌شود و تجربه‌ای نزدیک‌تر به یک اپلیکیشن مستقل ارائه می‌دهد.

Service Worker پروژه فایل‌های اصلی را Cache می‌کند تا نسخه نصب‌شده بتواند در حالت آفلاین نیز باز شود.

## بروزرسانی PWA

ابزار Newseek دارای مکانیزم بروزرسانی داخلی برای نسخه PWA است.

هنگامی که Service Worker جدیدی منتشر شود، یک اعلان کوچک با پیام «نسخه جدید Newseek آماده است» در پایین رابط کاربری نمایش داده می‌شود. کاربر با انتخاب دکمه «بروزرسانی» نسخه جدید را فعال می‌کند و صفحه یک بار Reload می‌شود.

اطلاعات و تنظیمات ذخیره‌شده کاربر در جریان بروزرسانی عادی PWA حذف نمی‌شوند.

## مدل‌های هوش مصنوعی

ابزار Newseek در نسخه فعلی امکان انتقال سریع پرامپت به این سرویس‌ها را فراهم می‌کند:

- ChatGPT
- Claude
- Gemini
- Perplexity
- Grok

ابزار Newseek مستقیماً به API این سرویس‌ها متصل نیست و جستجوی خبر را خودش انجام نمی‌دهد. وظیفه Newseek ساخت پرامپت است و اجرای جستجو توسط مدل انتخاب‌شده انجام می‌شود.

## تکنولوژی‌های پروژه

ابزار Newseek با تکنولوژی‌های اصلی وب توسعه داده شده است:

- HTML
- CSS
- JavaScript
- LocalStorage
- Clipboard API
- Web App Manifest
- Service Worker
- Cache Storage API
- Progressive Web App (PWA)

رابط کاربری، استایل‌ها و منطق اصلی پروژه در فایل `index.html` قرار دارند و برای اجرای پروژه به Backend یا فرایند Build جداگانه نیاز نیست.

فایل `manifest.webmanifest` اطلاعات نصب PWA، نام برنامه، رنگ‌ها و آیکون‌های آن را تعریف می‌کند.

فایل `service-worker.js` مسئول Cache فایل‌های اصلی، پشتیبانی از اجرای آفلاین و مدیریت فعال‌سازی نسخه‌های جدید است.

فونت Vazirmatn از طریق Google Fonts بارگذاری می‌شود و استفاده کامل از Newseek و مدل‌های هوش مصنوعی مقصد نیازمند اتصال اینترنت است.

## ساختار اصلی مخزن

- `index.html` — رابط کاربری و منطق اصلی Newseek
- `manifest.webmanifest` — تنظیمات نصب PWA
- `service-worker.js` — Cache، اجرای آفلاین و مکانیزم بروزرسانی
- `newseek-icon-192.png` — آیکون 192×192
- `newseek-icon-512.png` — آیکون 512×512
