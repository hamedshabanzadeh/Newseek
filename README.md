# نیوزسیک \| Newseek

ابزار **Newseek** یک ابزار تحت وب برای ساخت پرامپت حرفه‌ای جستجوی اخبار است که
موضوعات موردعلاقه کاربر را به یک پرامپت ساختاریافته برای پیدا کردن
مهم‌ترین و جدیدترین اخبار با کمک مدل‌های هوش مصنوعی تبدیل می‌کند.

نسخه آنلاین:\
https://hamedshabanzadeh.github.io/Newseek/

## درباره Newseek

ابزار Newseek به‌جای اینکه خودش یک خبرخوان یا موتور جستجوی مستقل باشد، به کاربر
کمک می‌کند درخواست جستجوی اخبار خود را به‌صورت دقیق و حرفه‌ای آماده کند.

کاربر موضوعات موردنظر و تنظیمات جستجو را انتخاب می‌کند و Newseek بر اساس
آن‌ها یک پرامپت ساختاریافته می‌سازد. این پرامپت برای کشف، اعتبارسنجی،
ارزیابی، حذف خبرهای تکراری، انتخاب خبرهای مهم و تکمیل اطلاعات خبر طراحی
شده است.

پس از ساخت پرامپت، کاربر می‌تواند آن را کپی کند یا مستقیماً یکی از مدل‌های
هوش مصنوعی پشتیبانی‌شده را باز کند. با انتخاب مدل، پرامپت ابتدا کپی می‌شود
و کافی است کاربر آن را در مدل موردنظر Paste کند.

## نحوه استفاده

1.  موضوع یا موضوعات موردعلاقه خود را اضافه کنید.
2.  بازه زمانی، تعداد خبر، زبان و سایر تنظیمات را انتخاب کنید.
3.  روی دکمه «ساخت پرامپت» بزنید.
4.  پرامپت تولیدشده را بررسی یا کپی کنید.
5.  یکی از مدل‌های هوش مصنوعی را انتخاب کنید.
6.  پرامپت کپی‌شده را در مدل Paste و اجرا کنید.

## مدل‌های هوش مصنوعی

ابزار Newseek در نسخه فعلی امکان انتقال سریع پرامپت به این سرویس‌ها را فراهم
می‌کند:

-   ChatGPT
-   Claude
-   Gemini
-   Perplexity
-   Grok

ابزار Newseek مستقیماً به API این سرویس‌ها متصل نیست و جستجوی خبر را خودش انجام
نمی‌دهد. وظیفه Newseek ساخت پرامپت است و اجرای جستجو توسط مدل انتخاب‌شده
انجام می‌شود.

## تکنولوژی‌های پروژه

ابزار Newseek با تکنولوژی‌های اصلی وب توسعه داده شده است:

-   HTML
-   CSS
-   JavaScript
-   LocalStorage
-   Clipboard API

رابط کاربری، استایل‌ها و منطق اصلی پروژه در فایل `index.html` قرار دارند
و برای اجرای پروژه به Backend یا فرایند Build جداگانه نیاز نیست.

فونت Vazirmatn از طریق Google Fonts بارگذاری می‌شود و استفاده کامل از
ابزار Newseek و مدل‌های هوش مصنوعی مقصد نیازمند اتصال اینترنت است.

## وضعیت پروژه

ابزار Newseek یک پروژه فعال است و نسخه فعلی آن با تمرکز بر ساخت سریع و دقیق
پرامپت جستجوی اخبار، تجربه کاربری ساده، رابط Responsive و انتقال آسان
پرامپت به مدل‌های هوش مصنوعی توسعه داده شده است.

توسعه‌های بعدی پروژه می‌توانند بر اساس بازخورد کاربران و نیازهای واقعی
